## Critical Anti-Patterns (do NOT repeat these)

| Pattern | Severity | Prevention |
|---------|----------|-----------|
| Re-attempting Xcode 26 xctest harness fix | blocking | `.planning/debug/xctest-launch-runningboard-error-5.md` is the canonical diagnosis — accept upstream-blocked. SPM `swift test` is authoritative; `scripts/check-app-builds.sh` covers compile-only sanity. |
| Touching STATE.md / ROADMAP.md from executor worktree | blocking | Orchestrator owns these; executors have FILE SCOPE that excludes them. |
| Parallel-executing wave plans that share files | advisory | Scan `files_modified` overlap + grep cross-plan imports before spawning parallel waves (Phase 3 W2 + Phase 5 W2 lessons). |
| Auto-merge from worktree isolation is non-deterministic | advisory | Always `git log` develop after each Agent returns; merge manually only if the agent's final SHA isn't already on develop. |
| Bash `${VAR:-default}` in build scripts when empty value is meaningful | blocking | Use `${VAR-default}` (no colon) when an explicit empty value is meant to mean "no default." Or branch on `CONFIGURATION` explicitly. The colon form bit `scripts/codesign.sh` line 17 — silently re-enabled Hardened Runtime on Debug builds, AMFI rejected, dyld aborted. Fixed in `2164400`. |
| Setting `statusItem.menu` to a context menu temporarily then clearing it | advisory | NSStatusItem can latch the menu reference on a separate runloop pass after the action selector returns — both left- and right-clicks then surface the menu, the action selector never fires again. Use `statusItem.popUpMenu(_:)` directly (deprecated since 10.14 but functional through Tahoe). Fixed in `d7a192a`. |
| Removing `type="module"` from a Vite-emitted `<script>` without restoring `defer` | blocking | `type="module"` is deferred-by-default; plain `<script src=>` runs immediately mid-`<head>` before `<body>` exists. React's `getElementById('root')` returns null and silently mounts nothing — no thrown error. Always emit `defer` when stripping `type="module"`. Fixed in `c951f12`. |
| Assuming all long-lived FDs come from our code | advisory | WebKit's GPU process opens system Metal libraries without O_CLOEXEC; lldb-attached debugging inherits debugger pipes. ChildSpawnGate's "fatal in Debug on any non-CLOEXEC FD" only makes sense when scoped to *developer-owned* file paths. Fixed in `ccf1d36`. |
