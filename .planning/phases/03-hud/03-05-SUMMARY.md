# Phase 3 Plan 5: Bundle Integration Summary

## One-liner

End-to-end HUD wiring — R3F bundle committed under `App/Resources/webview/`, rebuilt on every Xcode build by `scripts/build-webview.sh`, loaded by `AppDelegate.installBus()` in place of the 02-03 bus-harness, with a `HudStateCoordinator` + `busHudState()` bridge routing Swift state transitions through `WebviewBridge.send(.hudState(...))` and `markReady()` promoting `.booting → .idle` on handshake armed. Phase 3 closes: HUD-01 + HUD-02 + HUD-07 + HUD-08 + TEXT-02 all validated.

## What landed

### Task 1 — pre-build pipeline (commit `a9a1b86`)

- `scripts/build-webview.sh` (exec): pnpm install (content-hash-cached on `pnpm-lock.yaml` sha) + `@jarvis/bus build` + `@jarvis/hud build` + `rsync -a --exclude=bus-harness.html --exclude=.gitignore webview/packages/hud/dist/ → App/Resources/webview/`. The two excludes preserve 02-03's committed `bus-harness.html` (which `check-bus-harness-parity.sh` enforces byte-equality on) and the local `.gitignore` that keeps `assets/` out of version control.
- `project.yml` gained two `preBuildScripts` entries after the existing `check-no-evaluateJavaScript-calls` phase: `Check single-writer HUD state (HUD-08)` and `Build webview bundle`. The post-build codesign chain stays untouched — order is `preBuildScripts: [parity, protocol-version, no-eval, single-writer-lint, build-webview] → compile → postBuildScripts: [pre-codesign-verify, codesign, post-codesign-verify, pbxproj-lint]`.
- `App/Resources/webview/.gitignore` ignores the `assets/` subdirectory (regenerated on every build from `webview/packages/hud/dist/`).
- `App/Resources/webview/index.html` committed (649 bytes; references `./assets/index-*.js` and `./assets/index-*.css` relative paths per Vite `base: './'`).

### Task 2 — AppDelegate + Coordinator + Bridge (commit `cabc272`)

- **`App/HUD/HudStateBridge.swift`** (new, 25 LOC): `@MainActor public func busHudState(from app: HudState) -> Bus.HudState` — rawValue round-trip with `assertionFailure` on drift and `.idle` fallback in Release. This file is the ONLY App-side site that imports `Bus` to reach `Bus.HudState`; the coordinator stays bus-agnostic per Plan 03-01's invariant.
- **`App/AppDelegate.swift`** modifications:
  - New stored properties: `hudStateCoordinator: HudStateCoordinator?`, three `dormant{Agent,Voice,Confirm}Continuation` fields for Swift-6 task retention, and `webviewEntryFilename: String = "index"` as the W6 test seam.
  - `installBus()` now constructs the coordinator with an emit closure that builds `.hudState(busHudState(from: appState))` and dispatches to `bridge.send(_:)` on the MainActor; creates the three dormant AsyncStreams (Phase 4/5/6 replace them) and calls `coordinator.start(agent:voice:confirmation:)`; loads `index.html` via `webviewEntryFilename` instead of the 02-03 `bus-harness.html`. The 02-03 XCTest-host short-circuit pattern (deviation #5) is preserved — under XCTest, the `loadFileURL` step is skipped but the coordinator + bridge are fully constructed so tests can assert wiring without tripping the hard-block modal.
  - `bridge.onHandshakeArmed` closure now calls `hudStateCoordinator?.markReady()` alongside the existing `systemLogger.info` + `onBusArmed` call. This is the trigger that promotes `.booting → .idle` as soon as the webview is responsive.
- **`scripts/check-single-writer-hudstate.sh`**: allowlist extended to `HudStateCoordinator.swift + HudStateBridge.swift + AppDelegate.swift + BusOutbound.swift + Protocol.swift`. Already wired as a preBuildScript in Task 1 — activated from Task 2's commit onward.
- **`App/Tests/AppTests/HudStateCoordinatorBusWiringTests.swift`** (new, ~250 LOC):
  - `test_coordinatorConstructedInInstallBus` (W1): `delegate.hudStateCoordinator` non-nil post-`applicationWillFinishLaunching`.
  - `test_emitClosureBridgesToBusSend` (W2): end-to-end exercise of the exact closure shape AppDelegate installs. Constructs a standalone coordinator + FakeJSEvaluator-backed WebviewBridge; drives `markReady()` + `agentCont.yield(.thinking)`; decodes the FakeJSEvaluator's recorded calls and asserts `BusOutbound.hudState(.thinking)` is among them.
  - `test_markReadyCalledOnHandshakeArmed` (W3): coordinator pinned at `.booting` pre-handshake; promotes to `.idle` after `bridge.handleHelloAck(BUS_PROTOCOL_VERSION)`.
  - `test_appHudStateRawValueMatchesBusHudState` (W4): bidirectional table over `HudState.allCases` and `Bus.HudState.allCases` asserting `Bus.HudState(rawValue:)` / `App.HudState(rawValue:)` resolve for every case, plus a `busHudState(from:)` spot-check per case.
  - `test_dormantStreamsHeldByDelegate` (W5): all three continuations non-nil after installBus.
  - `test_installBusLoadsIndexNotHarness` (W6): sets `webviewEntryFilename = "UNSET"` pre-bootstrap, asserts `== "index"` post.
- **`App/Tests/AppTests/WebviewBundleLoadTests.swift`** (new, ~60 LOC):
  - `test_indexHtmlInRepoWebviewDir` (B1): `#filePath`-traversal from `App/Tests/AppTests/` up to repo root; asserts `App/Resources/webview/index.html` file exists. Catches "committed an index.html-less tree" before the pre-build rsync finds an empty dest.
