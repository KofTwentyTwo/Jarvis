# BLOCKING CONSTRAINTS — Read Before Anything Else

> Each constraint below was discovered through actual failure this session.
> Acknowledge each one explicitly before proceeding.

- [ ] **CONSTRAINT: GSD verification ≠ working app.** v0.12.0 was 9/9 phases / 43/43 plans / 100% per GSD. Multiple production-blocking stubs and unwired features were discovered in a single working session. Tests were unit-level only; no integration test exercised the assembled app end-to-end. **Until the audit (`/gsd-audit-milestone`) runs and the integration test target is in place, treat any phase verification as preliminary, not authoritative.**
- [ ] **CONSTRAINT: WKContentWorld isolates `window.*` property access.** The comment in `webview/packages/hud/src/main.tsx` was wrong on this point; tests bypassed it via the JSEvaluator seam. **Any future work touching the bus or webview MUST be smoke-tested with a real WKWebView, not via JSEvaluator mocks alone.**
- [ ] **CONSTRAINT: Compiler warnings were treated as noise.** Three "weak reference will always be nil" warnings on `NSMenuItem.target = ClosureTarget(...)` were the actual bug breaking every closure-driven menu item. **Resuming agent: do not silence Swift weak-ref/sendable warnings without proving the underlying invariant another way.**
- [ ] **CONSTRAINT: Stubs commented "Replaced in Plan 0X-0Y" rot.** `CameraCapture.captureFrame()` returns a 1×1 black-pixel JPEG with comment "Replaced by AVCapturePhotoOutput delegate flow in 07-05" — Phase 7 closed; never came back. **Phase F's `check-no-leftover-stubs.sh` linter is required infrastructure; until it lands, every "Replaced in X-Y" comment must be tracked manually.**

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---|---|---|---|
| Cross-world handoff via shared globals | Stub in `WKContentWorld(name:"X")`, page bundle in `.page` world, both touch `window.jarvisBus` thinking they share — they don't. | blocking | All bridge-worlds aligned to `.page`. New code MUST use the explicit `contentWorld` constructor parameter on `WebviewBridge`, never reintroduce a named world without an integration test that proves the bundle's handler reaches Swift. |
| Test seam that bypasses the bug class | `JSEvaluator` protocol let Bus tests run without a real WKWebView, so WKContentWorld behavior was never exercised. | blocking | Phase F1 — add a top-level `IntegrationTests` target that links the App + every package and runs handshake-end-to-end smoke tests through the real WKWebView. |
| `NSMenuItem.target = T()` weakly held | NSMenuItem.target is `weak`; assigning a fresh trampoline lets it deallocate immediately. Compiler warns "weak reference will always be nil." | blocking | `MenuBarContextMenu.makeItem(...)` keeps the trampoline alive via `objc_setAssociatedObject`. Pattern documented in commit `fix(menu)`. Must be applied to any future closure-driven NSMenuItem / NSToolbarItem. |
| Future-tense stub comments | `// Stub: replaced in 0X-0Y` where 0X-0Y closed and the stub stayed. | blocking | Phase F2 — `scripts/check-no-leftover-stubs.sh` build-time linter that fails on stub patterns without explicit `accepted_stub: true` in the matching plan frontmatter. |
| Single-slot pre-handler buffer | `_pendingHello` was a single slot; burst messages clobbered each other. | advisory | Use a FIFO queue for any pre-handler buffering. Pattern fixed in `Injection.js` commit `fix(bus): replace single-slot _pendingHello with FIFO queue`. |
| `NSLog("%@", str)` redacts to `<private>` | Used `NSLog` for boot-path diagnostics; messages were unreadable in Console. | advisory | For diagnostic logging that needs to be visible: use `os.Logger` with `, privacy: .public` interpolation. Pattern in `App/Diagnostics/BootDiag.swift` (uncommitted; will be stripped in Phase A2). |

<decisions_made>

- **Page world over named world** — collapsed `WKContentWorld(name:"JarvisBusWorld")` to `.page` for the bus. Original "page scripts can't observe" rationale was overengineering for a local file:// bundle we own end-to-end. Trade-off: lose token-isolation security against page scripts; gain working handshake. Acceptable for this app.
- **Stub auto-acks hello regardless of handler state** — `Injection.js` always handles hello at the stub layer instead of routing to bundle handler. Bundle's `case 'hello': break` is now dead code. Trade-off: bundle can never react to hello; we don't want it to.
- **Settings menu wired to wizard as stopgap** — Settings menu item now opens the wizard. Phase A3 replaces this with a real Settings panel.
- **`dev-reset.sh` is the dev contract** — every test cycle starts with `scripts/dev-reset.sh --yes` to wipe Keychain + UserDefaults + WebKit caches + TCC + Application Support. Without it, prior-run state contaminates new tests.
- **Multi-session audit-and-fix plan over inline whack-a-mole** — committed `.planning/AUDIT-AND-FIX-PLAN.md` rather than continuing to fix bugs ad-hoc. User asked for this explicitly.
